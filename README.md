## 開発用メモ

- 自由にスクリプトを試せるように
  [.gitignore](.gitignore) で zzz.* を無視している。
- pull リクエストは受けない (そもそも ないと思うが)
- issue のフォームは今後 以下のテンプレートを用意する予定
  (2026-02-18 済み)

| テンプレート | 内容                       |
|:-------------|:---------------------------|
| add_request  | 掲載のないギフトの追加要望 |
| fix_request  | 間違いの指摘、修正要望     |
