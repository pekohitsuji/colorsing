# ユーザーへの説明

- 本インストラクションは、指定した年月のカレンダーの HTML を生成する

# 定義

- `入力HTML`       : @yokotan/calendar/2026-08.html
- `入力用背景画像` : @yokotan/calendar/2026-08.png

- `年月` : 値は YYYY-MM 形式で `2026-07`. 生成したいカレンダーの年月.

- `出力HTML`       : @yokotan/calendar/{年月}.html
- `出力用背景画像` : @yokotan/calendar/{年月}.png

# 作業手順

`入力HTML` を基に `出力HTML` を生成せよ
